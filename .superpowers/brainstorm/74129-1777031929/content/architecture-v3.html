统一对话入口 + Agent 意图路由

用户只跟一个聊天窗口交互，Agent 判断意图

小程序 Tab 结构（3 个 Tab）
┌───────────────────────────────────────────────┐
│  TabBar                                                │
│  ┌──────────────────┬──────────────────────┐   │
│  │ 💬 对话（首页）  │  📅 日历              │   │
│  └──────────────────┴──────────────────────┘   │
└───────────────────────────────────────────────┘

Tab 1 — 对话（首页，主交互界面）
  • 聊天窗口，用户说/打字/语音
  • Agent 判断意图后分发处理
  • 记录完成后提供确认卡片

Tab 2 — 日历
  • 日历选择日期
  • 查看每日摄入汇总
  • 点击某天看当日食物列表

意图路由 vs 独立 Tab 对比

统一对话入口的收益

  • 用户不需要思考"我该点哪个按钮"——直接说就行
  • 语音输入体验极其自然：打开App→说话→完事
  • 对话历史本身就是饮食日志的补充上下文

需要注意

  • 意图分类准确率是关键，误判会让人很烦
  • 饮食记录的确认卡片需要在聊天流中自然嵌入
  • Page 从 4 个缩到 2 个，页面复杂度降低
