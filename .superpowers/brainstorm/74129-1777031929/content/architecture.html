核心设计决策

关键设计点

  • 语音与后端解耦 — 小程序端语音模块只产出文本，后端所有API只收文本
  • 食物解析链路 — 输入文本 → 查食物数据库 → 命中则返回，未命中则 LLM 估算并写回缓存
  • 对话独立模块 — 与食物记录 CRUD 解耦，对话模块有独立的 LLM 调用链路
  • 微信登录 — wx.login 换 openid → 后端签发 JWT → 后续请求 Header 带 Token
