Agent 工具集（Tools）
工具 功能 实现
search_food RAG 召回食物营养成分 向量库 + Embedding
save_record 保存确认后的饮食记录 PostgreSQL 写入
get_daily_summary 查询某日摄入汇总 PostgreSQL 聚合查询
query_history 查询一段时间的记录 PostgreSQL 范围查询
refuse 拒绝回答与饮食无关的问题 Agent 自身判断 + 拒绝

  Agent 调用 search_food("皮蛋瘦肉粥")
  → 向量检索 top-k 最相似食物
  → 返回营养数据 + 相似度分数
  → Agent 决定用哪个结果

ReAct Agent 的优势

  • Agent 自主决定调用哪个工具，不需要预设意图分类
  • 可以多步推理：比如查了粥，发现用户还说"加了个蛋"，再查鸡蛋，合并计算
  • 确认、修改、追问都在同一个推理循环中完成
  • LangGraph 提供状态管理和工具编排，比手动 if-else 健壮得多

代价

  • 每个用户对话都是一个多步推理过程，延迟和成本高于单次 API 调用
  • 需要管理对话状态 (checkpoint)，LangGraph 有内置支持
